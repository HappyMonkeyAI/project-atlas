# Project Atlas bootstrap

1. Read AGENTS.md, CONTEXT.md, MCP.md, SPEC.md, and TASKS.md.
2. Confirm the working tree and preserve pre-existing changes.
3. Run the local prototype with npm run dev.
4. Verify the primary views and inspector in a browser.
5. Confirm the vault path before indexing private material.
6. Add a source manifest before generating graph edges.
7. Run applicable V0–V3 checks before calling a feature Done.
8. Ask before committing, creating branches, setting remotes, or pushing.
