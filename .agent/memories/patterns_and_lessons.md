# Patterns and lessons

## 2026-09-09

- A shared graph model is more important than any individual visualization.
- Existing TaskMaster and Vibes Dashboard work provide reusable adapters and shell patterns.
- The local vault path needs explicit confirmation before indexing.
- Browser verification should use a dedicated non-user tab and preserve the deliverable preview.

## Hy Memory must not share Codex Neo4j

Optional agent-memory graph extras must not share the HappyMonkey docs-RAG Neo4j instance. Keep memory-system candidates at disposition `benchmark` until a scrubbed disposable smoke says otherwise.

## Skill packs need a safety gate first

Treat third-party agent skill packs as untrusted until a local SkillSpector (or equivalent) scan says otherwise. Prefer pattern notes over install when scores are CRITICAL / DO_NOT_INSTALL.

## Owned GitHub promote is curated, not flood

Reconcile personal/org GitHub activity into Atlas by promoting only high-signal products in daily use; park games/media/client noise on a watch list.
